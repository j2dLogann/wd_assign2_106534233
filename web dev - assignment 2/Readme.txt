Website, "CineHolder" is a movie discovery and ticket booking platform. The platform's "Home" page will introduce the user to the platform, including a "step-by-step" 
guide at the bottom of the page which simplifies system (the "service cards" at the bottom will direct the user to the respective page on the website when clicked). Users 
will be able to to browse available movies on the "Movies" page and receive recommendations based on their input within the "Recommendations" page. 
Users will be able to register for an account in the "Register" page where an established "error message" will appear when inputs are not properly validated. 
Lastly, movie tickets and sessions can be booked by the user on the "Book" page. Users will be instructed to complete and submit the form regarding personal details, 
movie selection, screening, ticket quantity, choice of payment, and payment details--similar to the "Recommendations" page validation process--the 
"Book" page will display an error message for invalid inputs in specific fields.

The JavaScript, "script.js", is formatted and sectioned into 3 main blocks, "Booking page", "Recommendation page", and "Registration page". Each block consists of relevant 
scripts pertaining to the titled block (e.g, Recommendation page will involve scripts regarding user input evaluation and matching elements for the Recommendations page). 
Specifically, the Registration page block within the JavaScript includes validation elements that compares the user's input inside of specific input fields with a set of 
established requirements. The user's input is taken and is stored within the variables in the JavaScript, the variables are compared against the requirements which are 
programmed inside of the JavaScript, error messages are displayed to the user when their inputs does not satisfy those requirements and the submission is blocked. 
Unsatisfied requirements adds strings of text to an error popup for user's to address and the function is returned "false" to prevent submission, otherwise, returns true 
when the errors have been corrected allowing the form to submit.

Limitations associated with the platform relates to the rule-based logic adopted to match suitable movies to the user's preferences within the "Recommendation page". Due to 
the short list of available movies, the script used to evaluate user input was challenging to learn and implement. As a result, most selections provided similar movie 
evaluations and particular selections would give "no results", users then are forced to change their preferences to get a result.
